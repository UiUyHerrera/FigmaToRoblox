# Tags

Add tags at the end of a layer name, separated by underscores (`Buy_button_smooth`), or pick them in the plugin's Interact tab. Tags marked with `:x` take an argument, like `_open:Shop`.

This file is generated by `tools/tags-doc.js` from `figma-plugin/code.js` (81 tags). Don't edit it by hand.

## Structure

| Tag | What it does |
|---|---|
| `_button` | Clickable button with hover/press feedback. Put it on the whole button frame. |
| `_scroll` | Scrolling window. Put it on a frame with Clip content; children outside the frame become scrollable. |
| `_panel` | A panel buttons can open/close. Name it e.g. Shop_panel. Hide it in Figma to start closed. |
| `_open:x` | Button that opens the panel named in the argument (_open:Shop). |
| `_close` | Button that hides its parent panel (or the whole GUI). |
| `_toggle:x` | Button that opens/closes the named panel (_toggle:Shop). |
| `_image` | Export this layer (with its children) as a single image. |
| `_frame` | Force an editable Frame; unsupported paints are dropped. |
| `_txt` | Force live text even if it has unsupported fills. |
| `_ignore` | Skip this layer. |
| `_keep` | Keep this layer separate when its parent is exported as an image. |
| `_nodim` | Image inside a button that should not darken on hover. |
| `_fit` | Text auto-shrinks to fit its box (TextScaled). |
| `_list` | Arrange direct children in a UIListLayout (equal gaps). |
| `_grid` | Arrange equal-sized children in a UIGridLayout. |
| `_textbox` | Player text input. The drawn text becomes the placeholder. |
| `_canvas` | CanvasGroup: clips to rounded corners and fades as one. |
| `_aspect` | Keep width/height ratio (UIAspectRatioConstraint). |
